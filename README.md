**Download:** [Frekans Studio for Windows x64](https://github.com/frekans911/frekanslol/releases/latest)

**Premium:** A paid license is required to access Premium functionality. The installer is free to download; access is not free. **Core capabilities:** Official Skin management, Custom Skin import/management, supported mod organization, in-app account licensing, and Windows distribution.

**Compatibility notice:** Compatibility can vary with game updates and mod packages. Compatibility varies with game updates and mod packages. The Windows installer is **unsigned**; verify the SHA-256 hash from the download section before running it.
